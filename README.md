## ⚠️ Condiciones Generales del Módulo

1. **Obligatoriedad del APTO:** Obtener la calificación de **APTO** en la entrega del Anteproyecto es requisito indispensable para continuar con el desarrollo del módulo.
2. **Encadenamiento de Checkpoints:** La entrega puntual de los hitos intermedios en GitHub es obligatoria para mantener el derecho a revisión previa y seguimiento por parte del profesorado.
3. **Corte del 50% por Subbloque:** Para hacer media en la calificación final, es necesario obtener al menos un **5 sobre 10 (50%)** en cada uno de los subbloques evaluables (Interfaz, Frontend, Backend, Despliegue, Documentación y Exposición).
