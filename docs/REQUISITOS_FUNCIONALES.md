### Requisitos Funcionales Mínimos (Obligatorios para todos)

- **RF-01 (Autenticación):** El sistema permitirá el registro de usuarios, login con credenciales válidas y logout.
- **RF-02 (Perfil):** El usuario autenticado podrá ver y modificar su información de perfil.
- **RF-03 (Roles):** El sistema restringirá accesos y acciones diferenciando entre el rol [ej: Usuario/Cliente] y el rol [ej: Administrador].
- **RF-04 (CRUD Principal):** El rol [Administrador/Gestor] podrá crear, listar, editar y borrar [ej: Productos / Citas / Vehículos].

### Requisitos Funcionales Específicos 

*Ejemplos:*
- **RF-05 ([Nombre de la funcionalidad]):** El [tipo de usuario] podrá [acción concreta] para [objetivo del negocio].
- **RF-06 ([Nombre de la funcionalidad]):** El sistema permitirá/realizará [acción automática o interacción avanzada].

---

#### 💡 Ejemplos de posibles RF en los proyectos tipo vistos en clase

##### 🛒 Tipo E-Commerce / Tienda Online
* **RF-05 (Búsqueda y Filtro de Catálogo):** El cliente podrá buscar productos por palabra clave y filtrarlos por categoría, rango de precio o disponibilidad de stock.
* **RF-06 (Carrito y Tramitación de Pedido):** El cliente podrá añadir o eliminar productos de su cesta, seleccionar la dirección de envío y formalizar el pedido.

##### 📅 Tipo Sistema de Reservas y Citas (Booking / Servicios)
* **RF-05 (Reserva en Calendario):** El usuario podrá seleccionar fecha, hora y profesional o servicio disponible mediante un calendario interactivo.
* **RF-06 (Gestión y Cancelación de Citas):** El cliente podrá consultar el historial de sus reservas activas y cancelar una cita previamente programada.

##### 📊 Tipo Gestor de Tareas / CRM / ERP / Panel Interno
* **RF-05 (Asignación y Estado de Tareas):** El gestor podrá asignar tareas a un usuario específico y actualizar su estado dentro de un tablero o flujo de trabajo.
* **RF-06 (Generación de Reportes):** El administrador podrá consultar el resumen de actividad del sistema y exportar un informe de métricas en formato PDF o CSV.

##### 💬 Tipo Plataforma Social / Comunidad / Gestor de Contenidos
* **RF-05 (Interacción y Feedback):** El usuario autenticado podrá publicar comentarios y valorar (dar *like* o puntuación) las publicaciones de otros usuarios.
* **RF-06 (Sistema de Notificaciones):** El sistema alertará al usuario en la plataforma cuando otro usuario interactúe con su contenido o cambie el estado de su cuenta.
