### Requisitos Funcionales Mínimos (Obligatorios para todos) --> Debeis adaptarlo a vuestra aplicación

- **RF-01 (Autenticación):** El sistema permitirá el registro de usuarios [ej: Cliente / Gestor / Colaborador], login y logout.
- **RF-02 (Perfil):** El usuario autenticado [ej: Cliente / Gestor / Colaborador] podrá ver y modificar su información de perfil.
- **RF-03 (Roles):** El sistema restringirá accesos y acciones diferenciando entre los roles [ej: Usuario Anónimo, Administrador, Cliente].
- **RF-04 (CRUD):** El usuario [ej: Cliente / Gestor / Colaborador] tendrá la posibilidad de crear, listar, editar y borrar elementos [ej: Productos / Citas / Vehículos].

### Requisitos Funcionales Específicos --> Propios de vuestra aplicación

*Ejemplos:*
- **RF-05 ([Nombre de la funcionalidad]):** El [tipo de usuario] podrá [acción concreta] para [objetivo del negocio].
- **RF-06 ([Nombre de la funcionalidad]):** El sistema permitirá/realizará [acción automática o interacción avanzada].

---

#### 💡 Ejemplos de posibles RF en los proyectos tipo vistos en clase

##### 🛒 Tipo E-Commerce / Tienda online
* **RF-05 (Búsqueda y filtro de catálogo):** El usuario cliente podrá buscar productos por palabra clave y filtrarlos por categoría y rango de precios.
* **RF-06 (Carrito):** El usuario cliente podrá añadir o eliminar productos de su cesta de la compra.
* **RF-07 (Tramitación de pedido):** El usuario cliente podrá formalizar su compra seleccionando la dirección de envío y realizando el pago.

##### 📅 Tipo Sistema de reservas y citas (Booking / Servicios)
* **RF-05 (Reserva en calendario):** El usuario podrá seleccionar fecha, hora y profesional o servicio disponible mediante un calendario interactivo.
* **RF-06 (Consulta de citas):** El cliente podrá consultar el historial de sus reservas activas.
* **RF-07 (Cancelación de citas):** El cliente podrá cancelar una cita previamente programada.

##### 📊 Tipo Gestor interno
* **RF-05 (Incidencias de stock):** El sistema mostrará alertas visuales cuando un producto esté por debajo del stock mínimo establecido.
* **RF-06 (Control de stock defectuoso):** El sistema permitirá registrar productos rotos/defectuosos para restarlos del inventario.
* **RF-07 (Informes):** El encargado podrá consultar el desglose de ventas diarias/mensuales y exportar en PDF un informe desglosado.

##### 💬 Tipo Plataforma Social / Comunidad / Gestor de Contenidos
* **RF-05 (Publicación):** El usuario autenticado podrá realizar publicaciones.
* **RF-06 (Interacción):** El usuario autenticado podrá publicar comentarios y valorar (dar *like* o puntuación) a las publicaciones de otros usuarios.
* **RF-07 (Sistema de notificaciones):** El sistema enviará un correo al usuario autenticado cuando otro usuario interactúe con su contenido.
