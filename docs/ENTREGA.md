Todo repositorio de entregable final debe incluir:

### 1. Código fuente definitivo en Github

### 2. Documentación final en Github (`README.md`)

Un archivo `README.md` que contenga **al menos** las siguientes secciones:

1. **Información general**
   * Autor (Nombre y apellidos).
   * Título del proyecto.
   * Tipo.
   * Temática.
   * Descripción general.
2. **Análisis**
   * Requisitos funcionales.
   * Roles del sistema.
   * Vistas.
3. **Diseño**
   * Stack tecnológico elegido.
   * Enlace al prototipado de alta fidelidad.
   * Diagrama del Esquema Entidad/Relación.
4. **Documentación técnica**
   * Enlace a la URL de la aplicación en producción.
   * Guía de instalación en local.
   * Vídeo-manual de uso del sistema.
   * Bitácora de seguimiento del proyecto.
   * Posibles mejoras a futuro.
   * Bibliografía. *(Nota: Wikipedia y ChatGPT no se consideran fuentes bibliográficas válidas).*

### Elementos extra que podríais incluir para darle más calidad a vuestra documentación (sugerencias)
* Documentación sobre la arquitectura técnica y flujo de datos. Esquema gráfico que muestre cómo se conectan el Frontend, el Backend y la Base de Datos, acompañado de una breve explicación paso a paso de cómo viaja la información en la aplicación (por ejemplo, durante el proceso de login o al guardar un registro).
* Diagramas de Casos de Uso, Secuencia, Clases, etc.
* Capturas de pantalla de vuestra aplicación en funcionamiento.
* Etc.
